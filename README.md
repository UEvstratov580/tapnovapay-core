## 📱 Про проект

**TapNovaPay Core Wallet** - офіційний криптовалютний гаманець для токенів TNP.

### ✨ Особливості
- Безпечне зберігання TNP токенів
- Підтримка Windows, Linux, macOS
- Інтуїтивний інтерфейс
- Шифрування даних

## 📦 Встановлення

### Windows
1. Завантажте `TapNovaPay-Core-Windows.zip` з [Releases](https://github.com/UEvstratov580/tapnovapay-core/releases)
2. Розпакуйте архів
3. Запустіть `run.bat`

### Linux
```bash
wget https://github.com/UEvstratov580/tapnovapay-core/releases/latest/download/TapNovaPay-Core-Linux.tar.gz
tar -xzf TapNovaPay-Core-Linux.tar.gz
cd TapNovaPay-Core
./run.sh
```

### macOS
```bash
curl -L -O https://github.com/UEvstratov580/tapnovapay-core/releases/latest/download/TapNovaPay-Core-macOS.zip
unzip TapNovaPay-Core-macOS.zip
cd TapNovaPay-Core
open TapNovaPay.app
```
